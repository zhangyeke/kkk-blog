# 博客 SEO 优化与内容建议

## 本轮技术调整

- 正式站点地址默认为 `https://kkk-blog-umber.vercel.app`，可以通过 `NEXT_PUBLIC_SITE_URL` 覆盖。上线前确认它指向稳定的正式域名，不要把临时 Preview 域名设为 canonical。
- `app/sitemap.ts` 每小时重新生成，收录公开博客入口、存在已发布文章的启用分类和已发布文章；草稿、后台、登录、个人中心和写作页面不进入 sitemap。
- `app/robots.ts` 公开抓取入口并指向 sitemap。隐私/操作页面使用 `noindex`；搜索词结果不收录，分类与分页有独立规范网址。
- 文章页的摘要由正文提取，结构化数据使用可见的标题、作者、分类、封面和发布时间。文章正文用安全的 Markdown 渲染，原文不会被自动改写。
- 文章列表首屏在服务器输出；分类与上一页/下一页使用普通链接，搜索结果仍可使用，但标记为不收录。

每篇文章建议围绕一个明确问题或地点，标题准确描述内容；正文先给结论，再给步骤、例子和限制。关键词短语用于帮助选题和组织内容，不要机械重复在标题和正文中。为相关文章互相添加有意义的链接，避免重复发布只替换关键词的页面。更新文章时同步检查标题、摘要、正文日期和示例是否仍然准确。

## 站长平台上线清单

1. 在百度搜索资源平台、Google Search Console 和 Bing Webmaster Tools 添加并验证正式站点。
2. 提交 `https://kkk-blog-umber.vercel.app/sitemap.xml`，并分别检查首页、文章列表、分类页、文章详情页是否可抓取。
3. 观察索引覆盖、搜索查询、展示、点击和点击率；对未收录页面先用 URL 检查工具确认抓取和规范网址，再按诊断修复。
4. 持续查看 Core Web Vitals 和移动端体验数据；只有数据表明有问题时再针对图片、字体或客户端脚本优化。

Sitemap、metadata 和结构化数据只能帮助搜索引擎发现、理解网页，不保证被收录或排到特定位置。排名还取决于页面是否真正满足搜索者需求、内容质量和站点长期表现。
